# Retail Pulse

Retail Pulse is an e-commerce sales and revenue analytics project built using the Olist Brazilian E-Commerce dataset.

## Objective

Analyze e-commerce sales data to identify trends, revenue drivers, customer behavior, product performance, seller performance, and other actionable business insights.

## Dataset

Olist Brazilian E-Commerce Dataset

The dataset contains multiple related tables representing customers, orders, order items, products, sellers, payments, reviews, and other e-commerce entities.
