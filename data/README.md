# Data Folder

- `rfm_segments.csv` — customer RFM segments (Recency, Frequency, Monetary + cluster label), 
  generated by `notebooks/02_rfm_segmentation.ipynb`. Used as a data source in the Power BI 
  dashboard's Customer Segments page.
- `master.csv` — NOT included in this repo (46MB, exceeds comfortable repo size for GitHub). 
  Regenerate it by running `notebooks/01_eda_datacleaning.ipynb` end-to-end against a 
  PostgreSQL database built from `schema/table_structure.sql`.

**Dataset source:** [Olist Brazilian E-Commerce Dataset](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) (Kaggle)
